# To Do List

Небольшое приложение для управления списком задач на чистом JavaScript (без фреймворков и TypeScript). Проект — учебный, сделан для отработки ООП-подхода на классах, работы с DOM и вёрстки по методологии BEM.

## Возможности

- Добавление и удаление задач
- Отметка задачи как выполненной (чекбокс)
- Удаление всех задач сразу (с подтверждением)
- Поиск задач по названию
- Переключение светлой/тёмной темы
- Счётчик задач
- Сохранение состояния между перезагрузками страницы через `localStorage`

## Стек

- HTML5 (семантическая вёрстка, доступность)
- SCSS (BEM, CSS-переменные для темизации)
- Vanilla JavaScript (ES-классы, `data-js-*` атрибуты для селекторов)

## Архитектура

Логика построена на двух классах:

- **`ToDoApp`** — управляет одним инстансом списка задач: находит DOM-элементы внутри корневого контейнера, навешивает обработчики событий (добавление, удаление, поиск, чекбоксы, тема), синхронизирует состояние с `localStorage`.
- **`ToDoAppCollection`** — находит на странице все контейнеры `[data-js-todo-app]` и создаёт для каждого свой экземпляр `ToDoApp`.

Взаимодействие с DOM происходит через `data-js-*` атрибуты, отдельные от классов, которые используются для стилизации — это разделяет ответственность CSS и JS-хуков.

## Установка и запуск

```bash
git clone https://github.com/MuhammadLeziz/ToDoList.git
cd ToDoList
npm install
npm run sass-watch
```

Затем открыть `index.html` в браузере (например, через расширение Live Server в VSCode).
